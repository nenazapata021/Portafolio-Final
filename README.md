# Portafolio De Edna

Proyecto personal desarrollado con Next.js, TypeScript y Tailwind CSS.

## Descripción

Portafolio profesional de Edna, diseñado para mostrar proyectos, habilidades y experiencia.

## Tecnologías

- **Next.js** - Framework React con App Router
- **TypeScript** - Tipado estático
- **Tailwind CSS** - Estilos utilitarios
- **shadcn/ui** - Componentes de interfaz

## Getting Started

```bash
# Instalar dependencias
pnpm install

# Ejecutar en modo desarrollo
pnpm run dev

# Build para producción
pnpm run build
```

## Deploy

Este proyecto está configurado para desplegarse en Vercel.
